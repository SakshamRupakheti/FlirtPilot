# FlirtPilot
Context-aware AI texting wingman for adults. Built with React, TypeScript and server-side AI.

## Application source

The application and server source are on [`codex/vercel-deployment`](https://github.com/SakshamRupakheti/FlirtPilot/tree/codex/vercel-deployment). Additional keyboard development is on [`codex/keyboard-offline-pilot`](https://github.com/SakshamRupakheti/FlirtPilot/tree/codex/keyboard-offline-pilot). This `main` branch contains the repository overview and license.
